# Španělský slovník 🇪🇸

Webová aplikace na učení španělských slovíček (kartičky, psaní, výběr ze 4). Funguje offline a jde přidat na plochu iPhonu.

## Nahrání na GitHub Pages

1. Na github.com vytvoř nový repozitář (např. `spanelstina`), klidně veřejný.
2. V repozitáři klikni **Add file → Upload files** a přetáhni všech 5 souborů:
   `index.html`, `sw.js`, `manifest.json`, `apple-touch-icon.png`, `icon-512.png`. Potvrď **Commit changes**.
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, složka `/ (root)` → **Save**.
4. Za 1–2 minuty bude aplikace na `https://TVOJE-JMENO.github.io/spanelstina/`.

## Přidání na plochu iPhonu

Otevři adresu v **Safari** → tlačítko **Sdílet** → **Přidat na plochu**.

## Důležité

- Data (slovíčka, statistiky) se ukládají jen v telefonu. V Nastavení občas dej **Exportovat zálohu**.
- Aplikace na ploše a Safari mají oddělené úložiště – používej tu z plochy.
- Když upravíš `index.html` a nahraješ znovu, aplikace si novou verzi stáhne při dalším spuštění s internetem. Data zůstanou.
